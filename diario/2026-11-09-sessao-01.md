## O que aprendi
- A API de um LLM é *stateless*: a cada chamada "a mesa começa vazia"; para o modelo lembrar, reenvio o histórico.
- Por isso, numa conversa longa, cada turno custa mais que o anterior.
- Tokens de saída custam ~5x os de entrada no Claude.
- Nos Claude 5.5, `temperature`/`top_p`/`top_k` dão erro 400; o controle novo é o `effort`.
